# Lifecycle Capability Matrix

The complete machine-readable lifecycle matrix is in `machine/lifecycle-matrix.json`. Values are restricted to `REQUIRED`, `NOT_APPLICABLE`, `EXTERNAL`, and `ALREADY_SUPPORTED`.

## Capability interpretation

- `ALREADY_SUPPORTED`: current code proves the capability at the selected boundary.
- `REQUIRED`: relevant to the selected owner but not proven complete in the current contract.
- `EXTERNAL`: performed by an upstream, operational, or source-specific owner rather than a CMS lifecycle.
- `NOT_APPLICABLE`: the row is not an editorial record for that capability.
