# WatanyBot Admin Authority Foundation

Phase 1 authority foundation for the WatanyBot Superadmin CRM Command Center.

It is authority-first and UI-second: permission matrix, denied-by-default route policies, immutable audit taxonomy, approvals, versioning, and a read-only command center model.

This does not mark the dashboard as BUILT. A module is BUILT only after route, API, DB, server authorization, audit event, UI, runtime behavior, and negative permission tests pass.
