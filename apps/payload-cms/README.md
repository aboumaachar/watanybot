# WATANYBOT Payload CMS

Local-only editorial authority for Procedures. Payload is a content authority and derived Gateway-admin projection; Gateway remains canonical for platform identity, sessions, roles, capabilities, business APIs, and audit authority.

Pinned foundation: Payload 3.63.0, @payloadcms/next 3.63.0, @payloadcms/db-postgres 3.63.0, Next 15.4.10, React 19.1.0, Node 24.16.0.

The `gateway-admins` collection has no local password strategy and cannot create, update, or delete records. SSO exchange and projection synchronization are intentionally the next integration step.
