# Watany Unified Feature Template

This folder contains the v1.4 unified feature template foundation.

Use `WatanyFeatureTemplate` for feature pages that need one consistent mobile-first shell with standardized hero, category tone, actions, metadata cards, content area, RTL-first layout, and evidence marker `data-watany-feature-template="true"`.

Mass migration is intentionally deferred. Pages should be migrated in small batches with browser/mobile proof.
