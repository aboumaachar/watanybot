# Watany Guided Help Pre-Landing Browser Smoke Checklist

1. Clear localStorage keys beginning with `watany:prelanding-guide:v1`.
2. Open the mobile shell/home.
3. Click a feature icon/card, for example Salary or Procedures.
4. Confirm popup appears before navigation.
5. Click Cancel and confirm route does not change.
6. Click again, then Proceed and confirm route changes.
7. Return home and click same route again; popup should not repeat after Proceed.
8. Clear only that route progress and test remind-me-later.
9. Clear again and test do-not-show.
10. Click Profile and confirm profile-completion benefit copy.
11. Click World Cup and confirm guided route is `/mcp/world-cup`.
