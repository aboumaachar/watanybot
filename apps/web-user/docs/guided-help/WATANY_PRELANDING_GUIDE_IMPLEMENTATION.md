# Watany Guided Help Pre-Landing Implementation

Creates a guided pre-landing provider before selected feature icon/card navigation.

Implemented:
- Centered Arabic popup before navigation.
- Proceed and Cancel.
- Do-not-show and remind-me-later.
- Per-user/per-route/per-guide localStorage progress.
- Programmatic hook: `useWatanyGuidedNavigation`.
- World Cup aliases normalized to `/mcp/world-cup`.

Manual browser smoke checklist is in `WATANY_PRELANDING_GUIDE_BROWSER_SMOKE.md`.
